# Put your first LoRA images here

This folder is for **reel symbols only** (recommended first project).

## What to put here

- PNG/JPG symbol art you own rights to
- Matching `.txt` captions with the same filenames

Example:

```
wild_01.png
wild_01.txt
scatter_01.png
scatter_01.txt
```

## Target count

15–40 images (25–40 is a sweet spot)

## Do not put here yet

- Character sheets
- Full bonus backgrounds
- Whole game screenshots
- Random mixed styles

Those belong in later folders / later LoRAs.
