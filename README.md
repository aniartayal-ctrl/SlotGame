# Global iGaming & Pragmatic Play Intelligence

An interactive, evidence-led report on the global online-gambling market, Pragmatic Play's footprint and game portfolio, popular mechanics, competitors, and strategic blind spots.

## View the report

Open [`index.html`](index.html) in any modern browser. The report is self-contained: it has no package install, build step, tracking, or external JavaScript dependency.

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Research principles

- Research cutoff: **29 July 2026**
- Monetary values use GGR/GGY (stakes less winnings) unless stated otherwise.
- Official regulator data, independent operator samples, and supplier claims are labeled separately.
- Differently scoped currencies and fiscal years are not combined into a false “global market share” ranking.
- Every material quantitative claim has a linked source in the report's source register.

This is strategic market research, not legal or investment advice.
